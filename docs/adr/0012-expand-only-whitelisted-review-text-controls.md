# 只啟動白名單評論全文展開控制

Google 公開貢獻者頁面會將較長評論縮成摘要，DOM 文字可能包含「…更多」。
只讀取現有文字無法取得全文，也可能把既有全文覆蓋成摘要。

抓取器可啟動評論卡片中、與評論文字節點位於同一父容器，且可見文字、
`aria-label` 或 `title` 精確符合「更多、顯示更多、閱讀更多、More、
Show more、Read more」的控制。按讚、有幫助、愛心、回覆、回應、分享等
互動詞另設拒絕清單；「更多動作」不符合精確白名單。抓取器仍不登入、不載入
Cookie，也不傳送滑鼠、觸控、鍵盤或表單輸入。

每次讀取目前可見卡片前先展開全文。若卡片仍存在全文展開控制，或擷取文字
仍以摘要標記結尾，該對象整輪巡查失敗並保存除錯資料，不寫入部分結果。
歷史資料中以摘要標記結尾的內容首次補成全文時視為資料修正：更新正文與內容
雜湊，但不建立評論修改事件或 Telegram 通知。
