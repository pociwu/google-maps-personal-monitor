# 依評論與圖片內容去除重複引用

Google 可能以不同來源網址重複提供同一則評論的相同圖片。系統以「評論 ID 加下載內容 SHA-256」判定唯一圖片：保留最早成功保存的引用，刪除同一評論內其餘相同內容的來源引用，並在後續下載完成時套用相同規則。

永久原圖仍依 SHA-256 保存，跨評論引用相同內容時各自保留關聯。這項決策以乾淨的展示與資料模型換取捨棄重複來源網址；不採用感知雜湊，以免誤合併外觀相近但實際不同的照片。

部署在清理既有引用前必須先建立 SQLite 備份，輸出掃描及刪除筆數；清理失敗時中止部署並保留原版本。後續巡查在圖片保存完成時立即套用去重規則。

評論的圖片數量及圖片修改判定同樣使用唯一 SHA-256 集合。僅 Google 來源網址增減不產生修改事件；唯一圖片內容真正新增或移除時才依既有規則通知，已永久保存的原圖不因目前集合移除而刪除。

圖片移除需連續兩次完整且圖片保存無失敗的巡查才能確認；新增圖片成功保存後立即生效。Telegram 修改通知只列出新增與移除數量，不重新發送整批圖片。

舊資料遷移時，去重後留下的既有唯一圖片全部先視為目前圖片；不根據缺乏狀態的歷史資料猜測圖片已移除，後續再由兩次完整缺失規則逐步校正。
